# AWS Cloud Foundations

Goal: Build entry-level Cloud + Security skills with hands-on labs and clear documentation.

## Focus areas
- IAM (least privilege)
- S3 security (encryption, policies, public access blocks)
- Networking basics (VPC concepts)
- Monitoring/logging (CloudTrail / CloudWatch)
- Cost awareness

## Deliverables
- Lab notes (Markdown)
- Security checklists
- Architecture diagrams (when relevant)
